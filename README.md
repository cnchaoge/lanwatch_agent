# 🔭 Lanwatch — 企业网络监控平台

> 你的网络什么时候"断"过，你什么时候才知道。  
> Lanwatch 让中小企业也能拥有 7×24 小时的网络值守服务。

---

## 痛点 — 你的企业是否正在经历

**"网络又断了？"** — 这是很多中小企业 IT 运维的日常。

- 🔌 交换机/路由器频繁死机，出了问题才知道，一修就是半天
- 📉 客户正在视频会议，关键时刻网络卡顿，损失不知找谁赔
- 🕐 夜里/周末网络故障，值班人员不知道，只能等上班才处理
- 📊 想监控网络质量，买的软件太贵，用不起来；开源的工具太复杂，招不到人会用
- 🤖 有多台路由器和服务器，每台都要单独配置，运维成本高

**Lanwatch 就是为这些场景设计的。**

---

## 它能做什么

### 🌐 断线早了知道 — 不再等客户投诉

- 网络质量下降时（延迟升高、丢包）**立即推送微信/钉钉/飞书报警**
- 设备彻底离线前就能预警，不用等对方先发现

### 🗺️ 故障快速定位 — 减少排障时间

- 内置 12 条诊断规则 + 引导式排查向导，出问题按图索骥
- 故障传播链分析：告诉你这个问题正在影响哪些设备

### 🚀 部署三分钟 — 不用写文档

- Windows 已发布安装包下载 exe，双击运行，填写企业名称，完成
- 自动隐藏到系统托盘，开机自启，真正"托管"
- 客户端源码覆盖 Windows / Linux / macOS / OpenWrt。已发布的安装包只有 Windows；Linux、macOS、OpenWrt 尚未提供安装包

### 📱 随时随地看 — 手机扫码就查看

- 手机端适配，打开就能看到网络状态
- 不用装 App，不用记地址，扫码直连

## 快速开始

### 第一步：下载 Agent

**最新正式版是 Windows v1.2.0**，不是 v1.3.0。  
👉 [下载 v1.2.0 的 lanwatch_agent.exe](https://github.com/cnchaoge/lanwatch_agent/releases/download/v1.2.0/lanwatch_agent.exe)  
发布页：[v1.2.0](https://github.com/cnchaoge/lanwatch_agent/releases/tag/v1.2.0)

`releases/latest` 目前仍指向这次 v1.2.0 的 exe。源码版本 1.3.0 已经在默认分支 `master` 上，**尚未打 tag、尚未创建 GitHub Release**，不能从 Releases 下载 1.3.0。

双击运行 → 填写企业名称 → 完成注册

Linux（`agent/linux/`）、macOS（`agent/mac/`）、OpenWrt（`agent/router/`）只有源码，没有安装包。Linux / OpenWrt 安装包仍是即将上线。

### 第二步：登录管理后台

访问你的服务端地址（如 `http://your-server-ip:8000`），用刚才注册的企业名称登录，即可看到本企业的网络状态。

### 第三步（可选）：配置报警

在管理后台设置 Server酱/钉钉/飞书 Webhook，网络异常时会自动推送微信消息到你的手机。

### 进阶（可选）：上门诊断工具 🩺

工程师带 U 盘到客户现场，5 分钟生成诊断报告——让客户亲眼看到网络问题：

```bash
git clone https://github.com/cnchaoge/lanwatch_agent.git
cd lanwatch_agent/diagnostic

# 主工具：纯标准库 LAN 扫描，零依赖
python lan_scanner.py

# 主动检测：需路由器 admin 凭证（通过环境变量提供，不进日志）
# 可选：本机装了 snmpwalk 时，active_diag.py 会把它当作一种探测手段；没装就跳过。
# 这是上门诊断工具，不是服务端 SNMP 轮询。
ROUTER_ADMIN_USER=admin ROUTER_ADMIN_PASS=xxx python active_diag.py

# 被动观察：只读模式，不发包，隐私友好
python passive_diag.py
```

报告自动输出到 `local_runs/`，可直接打开 HTML 给客户看。详见 [`diagnostic/SPEC.md`](diagnostic/SPEC.md) 与 [`docs/DEPLOY.md`](docs/DEPLOY.md)。

```
┌─────────────────────────────────────────┐

└───────┼──────────────┼──────────────┼─────┘
        │              │              │
        ▼              ▼              ▼
```

## 报警阈值参考

| 指标 | 警告 | 严重 |
|------|------|------|
| 延迟 | > 200ms | > 500ms |
| 丢包率 | > 20% | > 50% |
| HTTP 响应 | > 5s | > 10s |
| DNS 解析 | > 3s | > 10s |

阈值可在管理后台按需调整。
